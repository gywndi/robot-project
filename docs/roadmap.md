# 단계별 개발 계획

| 단계 | Python 개발 | 통과 기준 | 상태 |
|---|---|---|---|
| 0. 기반 | 패키지, mock, TOML, CLI, 제어/안전/통신 분리 | 실물 접근 없이 CLI·테스트 성공 | 초기 구현 |
| 1. 센서 | 확정된 센서 adapter, 시간·단위·유효성·신선도 표시 | 기준 계측기 비교, 누락/오래된 값 구분 | 예정 |
| 2. 기록 | CSV/SQLite, 측정 시각, 장치 ID, 오류와 설정 이력 | 재시작 후 기록 보존, 장시간 결측 확인 | 예정 |
| 3. 단일 장치 | 환기부터 수동 명령, 상태 읽기, 명령 확인 | 동의한 장치 하나에서 ON/OFF와 실측 효과 기록 | 예정 |
| 4. 환경 자동 제어 | 재배 단계별 목표, 가습·환기·온도·조명 정책 | 히스테리시스, 최소 운전 시간, 상충 명령·센서 장애 시험 | 예정 |
| 5. 운영 | 대시보드, 알림, 수동 전환, 복구·로그 관리 | 통신 단절/정전 복구 때 임의 자동 재가동 방지 | 예정 |
| 6. 영상 관찰 | 촬영, 고정 시점, 생장 기록, 검출評価 | 현장 이미지로 성능과 실패 조건 측정 | 예정 |
| 7. 로봇 기반 | RobotController, joint bounds, mock, Leader 읽기, 키보드 UI | 단일 관절 실측 한계와 쓰기 동의, 손목 회전 문제 해결 | 예정 |
| 8. 수확 | 카메라/로봇 좌표, 접근 경로, 파지·절단 도구, 힘 감지 | 모형 → 단일 버섯 → 제한된 반복 작업 검증 | 예정 |

각 단계는 mock 검증 → 읽기 전용 관찰 → 명시적으로 동의한 실물 쓰기 → 물리적 결과 기록 순서로 진행합니다. 영상 관찰은 환경 제어와 독립적으로 개발할 수 있습니다. 버섯 검출 성공만으로 로봇 수확을 허용하지 않습니다.

## 기존 실험에서 확인된 범위

과거 기록에는 Mac/LeRobot import, USB 식별, Follower 원시 위치 읽기, 집게·손목 소폭 명령, Enter 기반 입력이 있습니다. 현재 저장소에서 다시 실물 검증한 결과는 아닙니다. Leader는 포트만 식별했으며 읽기 검증은 미완료입니다. 세부 수치는 [시험 기록](test-results.md)에 보존합니다.
