# 준비 — 장치 선정과 시험 조건

## 재배 조건

- 버섯 종류, 품종, 배지/원목 방식, 재배 공간 크기를 기록합니다.
- 배양·발생·생육 등 운영 단계를 구분하고 단계별 온도·습도·CO₂·조명 목표를 검증된 재배 자료와 현장 측정으로 정합니다.
- 현재 설정 파일의 수치는 소프트웨어 시험용입니다. 생육 목표나 안전 한계로 사용하지 않습니다.

## 장치 목록

| 기능 | 준비할 것 | 먼저 확인할 항목 |
|---|---|---|
| 관찰 | 온습도 센서, CO₂ 센서 | 모델, 정확도, 결로 대응, 교정 방법, 샘플 주기 |
| 환기 | 팬/댐퍼와 제어기 | 정격, 통신 방식, 실제 풍량, 정전 시 상태 |
| 가습 | 가습기와 급수 감지 | 빈 물통, 누수, 과습 방지, 전원 복귀 동작 |
| 온도 | 냉난방 장치와 제어기 | 전력, 최소 ON/OFF 시간, 독립 과열 보호 |
| 조명 | 조명과 타이머/제어기 | 재배 단계별 시간표, 전원 정격 |
| 기록 | Mac, 저장 공간, 시각 설정 | CSV/SQLite 보관, 로그 용량, 알림 경로 |
| 영상·수확 | 카메라, 고정구, 로봇, 말단 도구 | 좌표 보정, 시야, 지지, 물리적 전원 차단 |

센서/제어기 모델과 USB·직렬·네트워크·마이크로컨트롤러 중 통신 방식을 확정한 뒤 adapter를 구현합니다. Mac에서 GPIO를 직접 구동한다고 가정하지 않습니다. 전원 장치와 물을 다루는 설비는 정격과 설치 조건을 별도로 확인합니다.

## 실물 연결 전 완료 조건

실물 쓰기는 사용자의 명시적 동의 후 진행합니다. 읽기 전용 연결도 SDK의 연결·해제 과정에서 설정이나 토크를 바꾸는지 소스로 확인합니다. 센서 누락·오래된 값·통신 실패 시 장치별 대응과 복귀 조건을 정합니다. 모든 장치를 일괄 OFF하는 것이 안전하다고 가정하지 않습니다.
